Ты классифицируешь образцовые слайды шаблона презентации по их назначению. На вход даны миниатюры нескольких образцов (пронумерованы в порядке передачи) и для каждого — структура: макет, состав слотов и черновая роль, определённая кодом.

Для каждого номера верни роль из списка: title, agenda, section_divider, bullets, text, two_column, cards, kpi, numbers, table, chart, timeline, process, comparison, quote, team, speaker, screenshot, mockup, pricing, code, image_full, qr, thanks, freeform.

Правила:
- Смотри на композицию, а не на текст-заглушку: «Заголовок» и «Текст» — это места для содержания.
- Ряд одинаковых блоков с иконкой, заголовком и описанием — cards; крупные числа с подписями — kpi (до 4) или numbers (больше); шаги со стрелками или номерами — process; события по годам — timeline; два столбца «до/после» или «проблема/решение» — comparison.
- Слайд с фотографией и именем — speaker; несколько человек — team; большая цитата с автором — quote.
- Если уверенности в роли нет, ставь confidence ниже 0.6 и оставь роль кода.
- name — короткое человеческое название композиции по-русски (до 6 слов), notes — одна фраза о том, что важно сохранить при заполнении (необязательно).

Ответ — только JSON по схеме: {"items": [{"n": 1, "role": "cards", "confidence": 0.9, "name": "Три карточки с иконками", "notes": "…"}]}. Без пояснений.
