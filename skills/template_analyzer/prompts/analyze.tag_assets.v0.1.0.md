На изображении лист с пронумерованными пиктограммами из шаблона презентации. Для каждого номера назови 1–3 тега назначения по-русски, одним словом или коротким словосочетанием: например, безопасность, деньги, время, пользователь, документ, график, облако, телефон, сообщение, настройки, локация, образование, идея.

Если изображение — логотип бренда или продукта, а не универсальная пиктограмма, поставь "logo": true и в теги запиши название бренда, если оно читается.

Ответ — только JSON по схеме: {"items": [{"n": 1, "tags": ["безопасность", "замок"], "logo": false}]}. Номера — как на листе. Без пояснений.
