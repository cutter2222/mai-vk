Ты размечаешь числовые факты из материалов презентации. Для каждого факта дан идентификатор, значение как в источнике и фрагмент текста вокруг него.

Для каждого факта определи по фрагменту:
- metric — что именно измеряет число: показатель именительным падежом, 1–5 слов («доля пропущенных важных уведомлений», «выручка», «экономия»);
- period — период, к которому относится значение, если он назван во фрагменте («2025 год», «май–июль», «за год»);
- subject — компания, продукт или сегмент, если он назван во фрагменте;
- comparison — с чем сравнение, если оно есть («год к году», «к плану», «с 31 % до 44 %»);
- confidence — уверенность от 0 до 1.

Правила:
- Используй только слова из фрагмента; не придумывай период, субъект и сравнение, которых там нет — оставь поле пустой строкой.
- Значение факта не переписывай и не пересчитывай.
- Если по фрагменту нельзя понять, что измерено, ставь confidence ниже 0.5.

Ответ — только JSON по схеме: {"items": [{"fact_id": "f3", "metric": "экономия", "period": "за год", "subject": "", "comparison": "", "confidence": 0.9}]}. Без пояснений.
