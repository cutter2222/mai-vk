# layout

Слой вёрстки: копия исходного пакета, клонирование образцов с графом связей, подстановка текста и фактов, нативные графики, таблицы, схемы из фигур, пиктограммы, ComposedDeck.

Вход: SlidePlan, TemplateProfile, исходный PPTX, ContentPackage. Выход: PPTX, ComposedDeck.

Реализуется на этапе 8; базовые операции проверяются на этапе 0A.
