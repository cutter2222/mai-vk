# layout

Слой вёрстки: исходный пакет как основа, клонирование образцов с графом связей, подстановка текста и фактов, нативные графики, таблицы, схемы из фигур, пиктограммы, ComposedDeck.

Вход: SlidePlan, TemplateProfile, исходный PPTX (тот же файл, по которому построен профиль — сверяется по `template_hash`), ContentPackage с каталогом ресурсов. Выход: PPTX, ComposedDeck, отчёт (время шагов, счётчики, проверка пакета, предупреждения).

| Модуль | Что делает |
| --- | --- |
| `compose.py` | оркестрация: `compose_deck()` — клон образца на каждый слайд плана, заполнение слотов по `element_ref`, правила незаполненных слотов и карточек, удаление образцов, номера слайдов, сохранение, проверка, ComposedDeck; `ComposeError` с кодами `compose_template_missing/mismatch/unreadable`, `compose_pattern_unknown`, `compose_sample_missing`, `compose_integrity` |
| `ooxml.py` | операции этапа 0A: `clone_slide()` (связи переписываются одной картой, диаграммы с книгами копируются), `replace_paragraph_text()`, `set_run_texts()`, `delete_slide()`, `keep_only_slides()`, `retarget_slide_links()` (переходы на слайд вне колоды снимаются, на образец — ведут на его копию; иначе убранное оглавление остаётся в файле лишним слайдом), `check_package()`, `compare_packages()` |
| `shapes.py` | объект по `p:cNvPr@id` внутри групп, обход с прокси python-pptx, удаление с чисткой опустевших групп и осиротевших связей, свободные id, EMU ↔ доли слайда |
| `package.py` | макеты по идентификатору профиля, плейсхолдеры для паттернов из макета, номера слайдов (`a:fld slidenum`), удаление неиспользуемых макетов (настройка `layout.prune_unused_layouts`) |
| `text.py` | текст с сохранением `a:pPr` и `a:rPr` первого фрагмента, явный `sz` из `fit.size_pt`, строки → абзацы образца или `a:br`, списки по маркированному абзацу, факты `{fact:id}`, `wrap="none"` для чисел в крошечных слотах, снятие `fontScale` автоподбора |
| `tables.py` | таблица образца перестраивается под набор данных (строки-шаблоны, сетка по пропорциям образца с минимальной шириной колонки, высота по строкам); без образца — `add_table()` со стилем темы и шрифтом профиля |
| `charts.py` | `ChartSpec` из блока и набора данных, `add_chart()` с цветами акцентов темы, шрифтом и кеглем профиля, легендой/подписями/осями по плану; диаграмма образца того же семейства получает `replace_data()` с сохранением оформления; для картинки диаграммы область — объединение слотов image паттерна |
| `diagrams.py` | схемы из фигур и соединителей в группе: process, cycle, pyramid, hierarchy, matrix, funnel, timeline, venn (не SmartArt) |
| `images.py` | картинка пакета в `p:pic` образца: новая медиа-часть, `cover` через `a:srcRect`, `contain` через рамку по пропорциям |
| `icons.py` | иконка шаблона по `media_path` профиля (связь на существующую часть), перекраска монохромных масок Pillow |
| `composed.py` | ComposedDeck по сохранённому файлу тем же обходом, что и анализ (`geometry.walk_shapes`, `StyleResolver`): объекты, bbox, z-order, группы, стили абзацев с источником, картинки с crop и ресурсами, таблицы, диаграммы с частью, `content_source`, `fit`, удалённые объекты, шрифты с подменой, статистика |
| `integrity.py` | `check_deck()`: `check_package` + число слайдов по плану, недостижимые части, цельность диаграмм (книга данных или кэш), цели связей слайдов |

Текст рядом с боковым декором: слот, перекрытый декором макета/мастера (`fixed_elements` вида decoration/logo от 2 % слайда) или большой статичной картинкой образца, сужается до свободной части (не уже 30 % слайда), получает явный `a:xfrm` и кегль по лестнице планировщика (для суженного слота — до 60 % исходного; `fit.action: narrowed_for_decor`, предупреждение `text_narrowed_overflow`, если не помещается и так); объекты в группах не трогаются.

Карточки групп без текста (иконки, подложки) считаются заполненными по ближайшему заполненному тексту (карточки или одиночного слота), а не по индексу: анализ часто кладёт иконки и тексты в группы разного размера. Правила незаполненных слотов: `number`-слот заполненной карточки с образцом-числом получает порядковый номер среди заполненных карточек (`content_source: generated`); остальной текстовый слот без блока удаляется (обязательный одиночный — с предупреждением `slot_unfilled`); крошечный слот (до 12 символов) с неслужебным текстом образца в заполненной карточке остаётся как `content_source: sample`; слоты table/chart/diagram без данных удаляются; картинка образца остаётся, если это фото или иллюстрация, и удаляется (`sample_image_removed`), если это картинка диаграммы, скриншот, мокап или паттерн про диаграммы; карточка без содержимого (по индексу во всех группах с равным числом карточек) удаляется целиком по `removable_object_ids`, подложки карточек — по ближайшей карточке, пустые статичные рамки, внутри которых остались только удалённые слоты, — тоже; логотипы, фон и прочая статика остаются; соединители, привязанные (`stCxn`/`endCxn`) к удалённому объекту или упиравшиеся концом в его рамку (либо только в уже снятую стрелку), убираются цепочкой, мелкий статичный декор без текста уходит с ближайшей пустой карточкой, свободные линии декора остаются.

Что не делается на этом этапе: повторное измерение переполнения (план несёт `fit.action`, `overflow` уходит предупреждением `capacity_overflow` в аудит), внешние библиотеки иконок (`icon.query`), генерация изображений (`image.generate`), клонирование заметок образца (заметки создаются из `slides[].notes` плана).
