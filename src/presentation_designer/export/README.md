# export

Слой экспорта: PDF через LibreOffice, миниатюры через pypdfium2, автономный HTML из ComposedDeck, кэш рендера, слоты рендера.

Вход: PPTX, ComposedDeck. Выход: PDF, PNG, HTML, манифест артефактов.

Есть с этапа 0A:

- `pdf.py` — `convert_to_pdf()`: отдельный процесс LibreOffice на конвертацию, временный профиль (копия подготовленного `/opt/lo-profile` из образа воркера, если есть), тайм-аут с завершением дерева процессов, очистка; `find_soffice()`, `soffice_version()`. Проверка рендерера при старте воркера (`pipeline/jobs.py: renderer_check`) использует эти же функции.
- `thumbnails.py` — `render_thumbnails()`: страницы PDF в PNG заданной ширины; все вызовы PDFium под одной блокировкой процесса, параллельность только процессами.

- `html.py` — `build_html()`: автономная страница колоды объектами слайда, а не его снимком (ТЗ п. 2.7: слайд-картинка не засчитывается). Всё берётся из ComposedDeck: рамка в долях холста → проценты, кегль в пунктах → `cqw` от ширины слайда, шрифт шаблона → `@font-face` с файлом того же резолвера, которым меряется вместимость слотов, картинки → `data:` из самого .pptx. Без обращений в сеть; текст выделяется и ищется.
- `deck.py` — `export_revision()`: экспорт ревизии варианта в каталог staging: `deck.pdf` через LibreOffice под слотом рендера, `thumbs/slide-NN.png` через PDFium (ширина `render.thumbnail_width_px`), `deck.html` через `html.build_html`. Если нативная разметка не построилась, остаётся прежний резерв — страница из миниатюр с текстом под ними. Подключён в `pipeline/real.py` (`export: real` там, где есть LibreOffice; иначе заглушка с отметкой `stub`).

Осталось от этапа 9: кэш рендера и визуальное сравнение. Замеры и ограничения: `docs/pptx-capabilities.md`.
