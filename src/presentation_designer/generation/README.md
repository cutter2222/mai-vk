# generation

Слой генерации: общий смысловой план StoryPlan, подбор паттернов кодом, три SlidePlan по оси плотности и подачи, проверка ёмкости слотов до вёрстки.

- `story.py` — StoryPlan из ContentPackage (этап 6): эффективный бриф (бриф пакета плюс явные настройки запроса), `content_hash` по нормализованному содержанию, брифу, модели, скиллу и схеме ответа, выдержка содержания с идентификаторами блоков, фактов, наборов данных и изображений, вызов скилла `story_planner` (рассуждение выключено, бюджет времени), сборка плана кодом: идентификаторы `t1..tN`, проверка ссылок, покрытие обязательных фактов и пунктов брифа, допущения из недостающих данных, проверка контракта и связей. Черновик без модели (`outline_without_model`) — только по явному запросу CLI `--no-model`, помечается предупреждением.
- `matching.py` — структура паттернов профиля (заголовок, одиночные слоты, группы карточек со слотом каждого вида на карточку), какие визуализации паттерн умеет показывать и сколько вмещает, кандидаты по подаче тезиса с учётом роли, вместимости, уверенности анализа и предпочтений варианта; титульный, разделители, содержание и финал — по ролям; ограничение серий одинаковых композиций (этап 7).
- `capacity.py` — подстановка фактов, измерение текста по файлам шрифтов рендерера (перенос по словам, высота строки из метрик, запас 0,92), ступени кегля из шкалы шаблона, сокращение без потери фактов (пункты и предложения без ссылок, части заголовка).
- `outline.py` — раскладка пользователя по слайдам: разделы «Слайд 1: …, Слайд 2: …» в материалах (текст из чата приходит файлом «Текст из чата.md»). Сюжет получает правило «раздел — один тезис», недостающий тезис строится из раздела, лишние вливаются в тезис раздела (`story._follow_outline`); план — обложка по титульному разделу («Заголовок:», «Подзаголовок:») и по пакету на раздел, без разделителей, оглавления и финала «Спасибо» (`variants._outline_structure`).
- `variants.py` — SlidePlan одного варианта: структура колоды, пакеты тезисов по разделам с бюджетом слайдов (нижняя граница пакета 0,7 цели для всех вариантов), запросы модели по пакетам параллельно (скилл `variant_planner`, один повтор пакета с подсказкой о переполнении, пустых слайдах — `density_hint` — и недоборе слайдов — `count_hint`), композиция по объёму содержания (`thin_ratio`/`right_size_pattern`: один-два пункта не идут на композицию из 4–7 карточек, колонки списков делят пункты между собой), сборка блоков по слотам и лестница ёмкости, разделение больших таблиц и переполненных списков, добор до числа слайдов слайдами в стиле шаблона (разделители, итог цитатой, оглавление, раскрытие тезиса из пояснения) раньше деления списков; при нехватке содержания колода короче, а не ошибка: просьба пользователя (точное число или диапазон) — предупреждение `slide_count_short`, которое задание пересказывает фразой «Просили N слайдов — содержания хватило на M» (`jobs._slide_count_short`), диапазон по умолчанию (запрос без `slide_count`) — `slide_count_relaxed` только в плане, покрытие обязательных тезисов, проверка контракта, кэш готовых планов по ключу (`PlanCache`), сравнение вариантов (`compare_plans`). Черновик без модели (`drafts_without_model`) — только CLI `--no-model` и тесты на реальных профилях.

Вход: ContentPackage, TemplateProfile. Выход: StoryPlan, SlidePlan × 3. Точки входа: `pipeline/real.py`, `cli/story.py`, `cli/plan.py`.
