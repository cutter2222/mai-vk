# parsing.template

Анализ шаблона: из PPTX — `TemplateProfile` (contracts/schemas/template_profile.schema.json) и миниатюры слайдов. Реализовано на этапе 5.

| Модуль | Назначение |
| --- | --- |
| `package.py` | целостность пакета (`PackageError` с кодом), тема, мастера, макеты, слайды, встроенные шрифты, направляющие из `viewProps` |
| `geometry.py` | плоский список объектов с bbox в долях слайда, пересчёт координат вложенных групп, поворот, crop, порядок, `element_ref`, байты картинок |
| `styles.py` | цвета темы с `clrMap` и модификаторами, шрифты `+mj/+mn`, наследование текста тема → мастер → макет → плейсхолдер → абзац → фрагмент с источником свойства |
| `classify.py` | слайд: образец / инструкция / каталог ресурсов / пустой / скрытый; маркеры-заглушки |
| `assets.py` | индекс картинок по sha256: иконка / логотип / фото / скриншот / мокап / фон / QR; листы иконок и теги через VLM |
| `fixed.py` | постоянные элементы мастера, макетов и повторяющиеся объекты образцов; динамические поля (номер слайда, дата) |
| `tokens.py` | палитра с областью действия и уверенностью, шрифты с доступностью в рендерере, шкала кеглей по ролям, поля и сетка |
| `patterns.py` | слоты образца, повторяющиеся группы (карточки), роль эвристикой и через VLM, ёмкость по `shared/text_metrics.py` |
| `guidelines.py` | правила оформления из текста шаблона с видом (typography, color, chart, table, icons, layout) |
| `analyzer.py` | порядок шагов, превью под слотом рендера, `llm_digest`, `profile_key`, отчёт с временем шагов |

Вход: путь к PPTX. Выход: `AnalysisResult(profile, previews, report)`. Вызовы: воркер через `pipeline/real.py`, CLI `presentation-designer analyze`. Результаты прогонов на четырёх шаблонах — `docs/template-analysis.md`.
