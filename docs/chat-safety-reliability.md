# Безопасность чат-правок — 27.09.2026

## Исправлено

- Информационные вопросы проверяются до правил удаления логотипа и вставки вложений.
  Явный `/edit` имеет приоритет над ключевыми словами внутри редактируемого текста.
  Вежливые просьбы по-прежнему распознаются как команды. Добавлено 19 случаев.
- Отмена офисной правки проверяет идентификатор документа до закрытия SDK и отправки
  запроса. Отмена перестройки проверяет задание и выбранный вариант.
- Последовательная отмена офисной копии допускается после отмены более поздней
  правки, только если текущий PPTX побайтово совпадает с результатом отменяемой
  правки. Посторонние изменения дают 409; история ревизий сохраняется.
- Перестройки ждут завершения всех заданий, включая последнее в шаге. Следующий
  шаг получает обновлённую ревизию. Ошибка останавливает цепочку. Repair также
  ожидается. Контекст читает актуальный React handle офисного редактора.
- Карточка отмены перестройки помечается отменённой только после успешного задания;
  отмена не добавляется в очередь следующего «отмени» как обычная правка.
- Выбор по имени больше не берёт первого/ближайшего кандидата без проверки:
  проверяются контекст группы, рамка (допуск 1 мм суммарно) и единственность.
  Проверены устаревшая рамка, дубликаты, неверная группа и перенумерация shape_id.
- Встроенный process разделяет крупную надпись (`subtitle`) и заголовок (`label`):
  три карточки больше не считаются шестью. Старые профили нормализуются при чтении.
  Регрессия сборки проверяет подложку и отличающийся цвет текста каждого описания.

   Остаётся live-проверка отмены вместе с переносом в настоящую офисную копию.

   Настоящий SDK и сохранение Document Server этим не проверены.

   нетронутых слайдов. Существующий live-тест чат-правки вызывает реальную модель;
   безмодельный roundtrip проверяет только no-op save и использует старые селекторы.
   Текущий frontend не развёрнут на стенде; браузерные mock-тесты выше не заменяют
   эту приёмку. Нужны изолированный проект и согласованный запуск актуального UI/API.
4. Полная визуальная приёмка в масштабе страниц, включая читаемость мелких подписей,
   остальные шаблоны и сравнение нетронутых слайдов после live-редактирования.

презентаций в этом этапе не было. Ограничение выбора: имя и рамка не являются
постоянным UUID; полная замена фигуры другой с тем же именем и геометрией требует
более сильного протокола идентификации.

## Продолжение после 299fc34

- `submit_revert` разрешает отмену более ранней правки после отмены поздней только
  при совпадении содержимого всех опубликованных файлов текущей и исходной ревизий.
  Сравниваются реальные файлы, а не только сохранённый хеш PPTX; план также защищён.
  Новая ревизия имеет номер `current + 1`, в истории остаётся фактическая база.
  Пара ревизий и адрес слайда дополнительно сверяются с записью правки.
- Кнопка отмены больше не исчезает только из-за увеличенного номера ревизии после
  предыдущей отмены. Решение о допустимости принимает backend, чужие изменения
  по-прежнему отклоняются.
- Runner ждёт подтверждения переноса rebuild/repair/revert в `ProjectOffice`.
  В режиме редактора требуется повторная готовность SDK, в preview — актуальное
  превью. Ошибка переноса останавливает следующие шаги; ошибка загрузки плана
  больше не превращается в фиктивный успешный перенос пустого списка слайдов.
- Несколько переносов в preview получают актуальную серверную ревизию перед
  каждым запросом, вместо повторного использования старого React-замыкания.
