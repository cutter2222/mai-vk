## Что уже есть и что нельзя сломать

- Шаблон до генерации открывается в ONLYOFFICE только для просмотра. В предыдущем
  живом Chromium-прогоне открылся шаблон на 55 слайдов.
- Обычные сообщения идут в контекстный чат; `/edit` явно запускает правку PPTX.
- История и ответы сохраняются сервером. Подсказки не переживают reload, повторный
  POST `/api/chat` пока не дедуплицируется.
- Первый опубликованный вариант открывается до завершения задания. Это **не**
  потоковая вставка слайдов. Завершение задания не должно пересоздавать iframe.
- Открытая офисная сессия закреплена за неизменяемым артефактом. Смена версии —
  только после безопасного сохранения/закрытия; поздняя AI-задача не затирает правки.
- В `./frontend/lib/state/projects.ts` есть ограниченный
  кэш временных ID сообщений → серверных ID. Его отдельная детерминированная
  регрессия на задержку после сохранения ещё нужна.

Для внешнего URL тестируется уже запущенная сборка: после изменения приложения

Без opt-in пропуск не считать успешной живой проверкой. После целевых тестов
прогнать полный backend-набор и остальные браузеры; результаты записать отдельно.
