# Генерация концепции по короткой теме

Тема, аудитория, цель и запрошенные разделы сами по себе не подтверждают содержание.
Если пакет содержит только эти поля, генератор явно маркирует результат как
**концепцию**, а не как презентацию подтверждённых характеристик или результатов.

## Реализация

- Классификация выполняется до построения StoryPlan. Учитывается извлечённое
  содержание, а не только наличие загруженного файла: пустой/непрочитанный файл
  не отключает ограничение.
- Абзацы, списки, цитаты, заметки пользователя, таблицы с данными и иллюстрации
  считаются предоставленным материалом. Это **не подтверждение их достоверности**
  или достаточности для всех запрошенных утверждений.
- Для topic-only пакета оба ИИ-этапа получают запрет на неподтверждённые
  характеристики, даты, результаты и прогнозы, включая утверждения без чисел.
  Допустимы вопросы для исследования, критерии оценки и явно обозначенные гипотезы.
  Поздние дозапросы `design.refill` и `feedback.ask_slots` также получают политику
  концепции, включая повторный запрос при нехватке места.
  Промпт требует предметных авторских предложений по теме, а не повторов оговорки
  об отсутствии источников. Это ограничение промпта, не гарантия качества ответа.
- Код независимо от ответа модели добавляет `topic_only_concept` в предупреждения
  StoryPlan и SlidePlan, оговорку в assumptions, префикс «Концепция:» в заголовок
  обложки и пояснение об отсутствии источников в её подзаголовок. Для английского
  используются английские формулировки; другие языки пока получают английскую оговорку.
- При подборе обложки учитывается маркированный заголовок. Маркировка остаётся
  в заголовке даже у шаблона без отдельного подзаголовка.
- Заданное число слайдов не меняется. Режим без модели также маркируется.
- Версии сборщиков повышены; результат классификации включён в ключ StoryPlan.
  Существующие презентации и пользовательские правки не перезаписываются.

## Ограничения

Это маркировка и ограничение промпта, **не независимый фактчекер**. Ответ модели
всё ещё может содержать неподтверждённое утверждение. Наличие одного содержательного
абзаца или изображения не доказывает, что все остальные тезисы опираются на источник.
Заметки брифа считаются материалом без семантической проверки: они могут оказаться
ещё одним заданием. Уменьшение объёма, уточняющий диалог и проверка достаточности
источников для каждого тезиса остаются отдельными этапами.

Регрессии: короткая тема iPhone 18, метаданные и обязательные разделы, пустая загрузка,
заметки/абзацы/списки/таблицы/изображения, русская и английская маркировка,
неизменность числа слайдов, модель без оговорки в ответе, оба ИИ-промпта и ключ кэша.
