- Защита содержания при повторной генерации (`retry_content_loss`), регрессии
  и replay-проверка текста в собранном PPTX. Предыдущие коммиты: `b8e99ae`, `d65bcbc`;
  их наличие в GitHub и авторство `Vasilisa-IT` подтверждены при передаче.

  по запросу, ленивые миниатюры и повтор ошибочного запроса страницы.
- Выбор объектов сохранённого PPTX, точечные и групповые ИИ-правки,
  проверки числовых фактов и сохранности текста/оформления вне выбора.

  строгая XML-проверка и узкая нормализация `matchingName` с аудитом исходных байтов.

- Исправление `fact_refs` в контексте дозаполнения слайда.
- Скрипты аудита, regression/live-тесты и opt-in precision-образ ONLYOFFICE.
  Precision-кандидат **не подключён** в основном Compose автоматически.

## Открытые задачи — начать здесь

1. **Исправить вёрстку без удаления содержания.** Наличие текста в PDF/HTML DOM
   не доказывает читаемость. В предыдущих проверках зафиксированы:
   - `mini/balanced`: слайды 4, 10, финал 12; аналогичные финалы compact 10 / detailed 15;
   - `mini/detailed`: наложения 5, 7, 12; выход текста на 8–9;
   - `rich`: показатели compact/balanced 2, detailed 3; возможное смешение подписей Q4;
   - особенно важно: `rich/compact` показывал **0 overflow** при видимом выходе текста.
   Эти дефекты при передаче заново не воспроизводились и не исправлялись.
   Сначала сопоставить расчёт вместимости с переносами и геометрией OOXML.
2. После исправления повторить replay, PPTX/PDF/HTML и визуальную проверку.
   Матрица девяти колод и незнакомый шаблон пока не приняты.
3. Перед выкладкой отдельно проверить UI save/reopen/download на актуальном backend.
   Исторические live-результаты разных ревизий не являются проверкой этой ветки целиком.
4. Precision ONLYOFFICE включать только после согласования: совместимые browser/server
   SDK, новый URL кеша, draining сессий, rollback и надёжная готовность конвертера.
5. Не запускать платные/live LLM-вызовы, расширенную матрицу и deployment автоматически.

## Получение и повторение

В существующем клоне сначала сохранить свои локальные изменения. Затем:

```sh

git pull --ff-only origin feat/ai-progressive-previews

```

```sh

.venv/bin/ruff check src tests scripts
pnpm -C frontend typecheck
pnpm -C frontend lint
git diff --check
```

Секреты, `.env`, закрытые шаблоны, содержимое `data/`, `runs/`, PPTX/PDF/PNG,
браузерные traces и архивы стендов не публикуются. Ссылки на локальные свидетельства
не означают, что эти файлы доступны после clone; при необходимости согласовать
отдельную безопасную передачу разрешённых материалов. Не копировать `runs/` целиком:
там могут быть JWT, подписанные URL и данные документов.
