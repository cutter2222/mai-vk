# Компактный ONLYOFFICE в проекте

Готовый PPTX открывается для редактирования прямо в области слайдов. Сворачивание
чата не пересоздаёт редактор. Кнопка «Сохранить и превью» сначала сохраняет SDK,
закрывает сессию и ждёт подтверждения сервера; только затем показывает превью
с выбором объектов для ИИ. «Редактировать слайды» возвращает встроенный редактор.
Из превью также доступен полноэкранный режим. ИИ-команда из встроенного редактора
использует существующую последовательность сохранение → ИИ-правка → открытие PPTX.

## Штатные настройки

Настройки задаются сервером внутри подписанной конфигурации:

- `uiTheme: theme-white` — встроенная белая тема без цветной офисной шапки;
- `compactHeader`, `toolbarHideFileName`, `compactToolbar` — компактные шапка и инструменты;
- `hideRightMenu`, `hideRulers`, `hideNotes` — больше места слайду при открытии;
- `zoom: -1` — вписать слайд в область редактора;
- `permissions.chat/comment: false`, `comments: false` — без второго чата и комментариев;
- `features.featuresTips: false` — без подсказок о новых функциях;
- плагины, макросы, справка, обратная связь и предложения функций отключены.

Редактирование, автосохранение и force-save остаются включены. Скачивание PPTX/PDF/HTML
остаётся в интерфейсе проекта и использует сохранённую серверную ревизию.
Скрытие панели заметок не удаляет заметки из PPTX. Панели и расширенные инструменты
можно снова открыть штатными средствами ONLYOFFICE.

ONLYOFFICE сохраняет пользовательские настройки темы, панелей и компактности
в localStorage; ранее выбранные настройки могут иметь приоритет над конфигурацией.
Мы не очищаем настройки пользователя и не внедряем CSS в iframe.

## Ограничения и источники

- [Standard branding](https://api.onlyoffice.com/docs/docs-api/usage-api/config/editor/customization/customization-standard-branding/)
  описывает темы и компактный UI. Наличие `theme-white` проверено в установленном
  Document Server; при обновлении/замене сервера проверяйте поддержку темы.
- [White label](https://api.onlyoffice.com/docs/docs-api/usage-api/config/editor/customization/customization-white-label/):
  выборочное скрытие вкладок и всего меню через `layout` требует расширенной
  White Label-лицензии ONLYOFFICE Docs Developer. Эти параметры не используются.
- `toolbarNoTabs` не убирает вкладки: меняет только их оформление и устарел с 8.2.

Стили слайдов, генератор контента и SDK обработки PPTX этими настройками не меняются.
